# English

## Overview

This repository documents structured hard-surface form studies
completed during the BlenderBros Shape Bootcamp course.

The primary focus is disciplined control of:

• primary and secondary forms  
• silhouette clarity  
• proportion and mass balance  
• surface flow and transitions  
• intentional form language  

Each folder represents a focused design exercise,
progressing from blockout to refined final form.

---

## Workflow Structure

```
Shape-Bootcamp-Study/
│
├── 01_Primary_Shapes/
├── 02_Silhouette_Study/
├── 03_Form_Language/
└── README.md
```

Each exercise may contain:

- `blockout.blend` — primary mass exploration  
- `refinement.blend` — proportion and surface refinement  
- `final.blend` — finalized controlled form  
- `render_final.png` — presentation render  
- `render_wireframe.png` — topology overview  

---

## Design Focus

This repository emphasizes:

- structured workflow
- clean topology discipline
- controlled surface design
- visual hierarchy of forms
- readable silhouette

No third-party course files or distributed assets are included.

# Русский

## Обзор

Этот репозиторий содержит структурированные упражнения
по работе с формой, выполненные в рамках курса
BlenderBros Shape Bootcamp.

Основной фокус:

• первичные и вторичные формы  
• читаемость силуэта  
• баланс масс  
• чистота переходов поверхностей  
• осознанный язык формы  

Каждое упражнение проходит стадии
blockout → refinement → final.

## Цель

контроля формы и чистоты поверхности.
